# 見積計算ルール

## 根拠と範囲

添付のSES2412064（要件定義）、SES2412064-2（設計・開発）のExcel原本を読み取り専用で調査した。計算式はブック内XMLから取得した。表示形式、セル配置、25行の機能入力枠はMDの制約にしない。

以下は確認した算出式の移植であり、Excelブック全体、マクロ、すべてのソリューションの互換性を保証するものではない。活動・体制の見積パターンはフェーズに合わせて選び、その工数をExcel由来の原価計算へ渡す。

## 工数

`ROUND(時間 * 2, 0) / 2` による0.5時間単位の四捨五入を使用する。

| 機能種別 | 内部設計 | PG開発 | プログラムテスト |
| --- | ---: | ---: | ---: |
| 画面 | 難易度×0.6h | 難易度×1.0h | 難易度×0.5h |
| 帳票 | 難易度×0.4h | 難易度×1.0h | 難易度×0.4h |
| バッチ | 難易度×0.4h | 難易度×1.0h | 難易度×0.5h |

機能ごと・工程ごとに丸めて合算する。内部設計レビューは内部設計合計の20%、指摘対応は5%をそれぞれ0.5時間単位で丸める。機能一覧の基準時間セルとWBSの `AD34`、`AD35`、`AD36`、`AJ40`、`AJ44` が根拠である。

活動工数は `数量 × 単位工数 × 人数`。既定はExcelの標準WBSにある `AD8`、`AJ8` などと同じ0.5時間丸め。要件定義ブックの `AD82`、`AJ82` など、丸めなしの個別式を採用する場合は活動行に `rounding: "none"` を明示し、根拠に元の式を記録する。行番号から暗黙に例外を適用しない。

体制工数は `人数 × 稼働率 × 月数 × 月間基準時間`。体制の積み方を追加したもので、Excel固有の人月換算式を確認したとみなさない。月間基準時間は必須入力とする。

## 原価・金額

原価明細シートの計算式を使用する。

| 算出 | 式・参照セル |
| --- | --- |
| ランク別原価 | 配賦工数×原価時間単価。`AA13 = R13*V13` など |
| 社内原価合計 | SE＋PG＋PJ管理＋予備。`AA21` |
| 見積総原価 | 社内原価＋外注費＋その他経費。`AA30` |
| 顧客向け概算 | `ROUND((社内原価＋外注費)/(1－粗利率)＋その他経費, -3)`。`AA31` |
| 粗利額 | 顧客向け概算－見積総原価。`V31` |
| 製造間接原価 | 原価対象社内工数×製造間接原価時間単価。`R33*V33` |
| PJ直接原価 | 見積総原価－製造間接原価。`AA34` |

間接原価を含む単価から直接原価を参考表示する。間接原価を追加で加算しない。外注費・その他経費に社内の間接原価時間単価を適用しない。

## 管理・予備の未入力時補完

明示的に `pricing.auto_overheads: true` を選んだ場合だけ、Excelの `O19`、`R19`、`O20`、`R20` を移植した補完を使用する。未指定は自動補完しない。明示工数がある場合はそれを優先する。

- PJ管理の判定額はSE・PG原価＋外注費。500万円超は15%、100万円超は10%、それ以下は5%。SE・PG作業工数に掛け、1時間単位で四捨五入する。
- 予備の判定額はSE・PG原価＋PJ管理原価。500万円超は15%、100万円超は10%、499,999円超は5%、それ以下は0%。管理を含む社内工数に掛け、1時間単位で四捨五入する。
- 準委任の予備は0。明示的な予備工数の配賦も拒否する。
- 管理・予備は別掲し、SE／PG原価へ重ねて含めない。自動補完分を含む原価対象工数と入力作業工数を分けて表示する。

## 確認例

要件定義の参考見積はSE作業295h、PJ管理43h、単価6,200円/h、経費12,640円、粗利率45%。原価合計2,108,240円、間接原価814,580円、PJ直接原価1,293,660円、顧客向け概算3,823,000円となり、原本表示値と一致する。原本のSE作業には他部署74hもあるが同じ見積単価であり、テストでは第3システム部へ集約した入力で算式の一致を検証する。他部署の原価マスタを収録したわけではない。
