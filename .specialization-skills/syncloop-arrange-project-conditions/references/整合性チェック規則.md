# 整合性チェック規則

## 判定と根拠

チェックは指定入力と整理項目に限定し、CC-01からCC-15を省略せず結果を示す。使える証拠に応じて次のいずれかに分類する。

| 結果 | 基準 |
| --- | --- |
| 整合 | 適用対象を判断でき、必要な情報が揃い、確認した範囲で不一致がない |
| 要確認 | 情報不足、曖昧さ、未承認・未合意、専門確認の必要などで判断できない |
| 競合 | 同じ対象・時点・条件について異なる根拠が両立しない |
| 対象外 | 今回は適用しないことを確認でき、理由と根拠がある |

結果には対象PC-ID、根拠WI-IDと該当箇所、観測内容、関連OI-IDを添える。未実施・読めない資料を整合扱いしない。「資料間で一致する」と「関係者が合意した」は別である。整合の結果だけで項目を承認・合意済みにしない。

## チェック一覧

| ID | 確認すること | 不足・競合を見つけた場合 |
| --- | --- | --- |
| CC-01 | 案件名、当事者、作業単位、対象期間が資料間で対応する | 別案件・別工程・別期間の混入と、単なる呼称違いを分ける |
| CC-02 | 業務・機能・工程・成果物の名称が統一され、別名は対応付けられる | 同じものか違うものかを確認し、無断で名称を統合しない |
| CC-03 | 概要と対象・対象外・外部連携の詳細が一致し、境界作業が明確である | 見積にない移行・教育・連携作業などの対象範囲を確認する |
| CC-04 | 前提として参照する資料が入力一覧にあり、版・日付・箇所で特定できる | 無版資料、未登録資料、未確認の参照先を示す。勝手に追加取得しない |
| CC-05 | 前提に対象、提供者、期限、未充足・変更時の扱いが必要に応じてある | 提供遅れや品質不足が作業に及ぼす影響と確認先を示す |
| CC-06 | 対象作業に担当があり、担当作業が合意対象の範囲を無断で超えない | 作業の空白・重複と、合意範囲の不明確さを分けて示す |
| CC-07 | 作業・担当・期限がスケジュール、役割分担、成果物で整合する | 同じ作業の担当・日付の違いを双方の根拠とともに示す |
| CC-08 | 提供、作業、レビュー、納入、受入の順序・期間が成立する | 前後関係の逆転、確認期間不足、対象期間外の節目を示す |
| CC-09 | 成果物または実施作業と完了条件・確認方法・判断者が対応する | 「次工程に支障なし」などの基準が曖昧なら観測・判断方法を尋ねる |
| CC-10 | 「支援」「適宜」「一式」などに必要な対象・方法・範囲がある | 曖昧語の存在だけで不備とせず、別資料で特定できるか確認する |
| CC-11 | 意思決定者、承認者、窓口、会議の権限が体制・役割と対応する | 仕様決定と費用承認を分け、権限の空白や呼称の不一致を示す |
| CC-12 | 資料・設備・ソフトウェアの提供者、利用条件、期間、返却・廃棄が明確である | 必要なものだけ確認する。元様式の別表への分離は求めない |
| CC-13 | 変更に影響評価、判断、合意、記録の手順がある | 追加費用・日程・範囲を誰がどう協議するか確認する。負担者を決めない |
| CC-14 | 未入力と対象外、事実と候補、承認と合意が区別される | 根拠のない確定・対象外、旧内容への合意の流用を示す |
| CC-15 | 参照する図・表の範囲・責任境界が判読でき、本文と一致する | 図の確認ができなければ要確認。色だけの識別や本文との違いを示す |

## 資料間の突合

- 見積・提案と、対象工程・作業・相手方作業・前提・対象外を突き合わせる。
- 要件・仕様と、対象機能・利用範囲・性能・受入基準を突き合わせる。
- 計画・WBSと、役割・成果物・提供期限・作業期間・判断の節目を突き合わせる。
- 体制・会議・合意記録と、決定権限・承認者・担当を突き合わせる。
- 構成・非機能要件と、環境・アクセス・利用制限・性能条件を突き合わせる。

入力候補の列挙順、更新日の新しさ、文書名だけで優先順位を決めない。対象範囲と合意された優先関係が根拠で確認できる場合はそれを示すが、他資料の更新や影響確認が不要とはみなさない。

## 未決事項と質問の粒度

同じ判断で解消できる指摘はOI-IDをまとめ、複数のPC-ID・CC-IDから参照する。単なる表記違いの質問を増やすより、範囲、責任、完了条件、期限に影響する質問を優先する。

未決事項には、種類、現状、競合する値・根拠、影響する項目、確認すべき判断、確認先、期限を記録する。確認先・期限の提案は `candidate` と明示し、人が引き受けた事実と混同しない。

## 機械確認と意味レビュー

IDの重複、参照切れ、明示された日付の前後関係は決定的な確認に向く。範囲の妥当性、責任の曖昧さ、基準の十分性、法的意味は人の判断を含む。推論を機械的な検証済み事実と称さず、仮定・限界を結果に記す。

契約条件に影響する競合や専門判断は、該当項目の確定を止める。入力・出力のゲートが成立している場合、指摘を含むレビュー案の作成は継続できる。
