# W-TBD 承認記録

このWorkの開始、目的・範囲・完了条件の変更、途中の正式反映（途中Sync）で、利用者に何を示し、何に同意を得たかを残す。TODOの追加・分割・順番の変更は承認不要で、作業メモの日付付き記録で追う。Workの終了は終了判断（版表・封印つき）が承認の記録になるため、ここには書かない。見出しは追記だけで、過去の見出しを消さない。

## Workセットで示す判断点

- 開始承認: 目的・期待する価値、対象／対象外、完了条件・確認方法、入力ベースライン（使う資料と版）
- 変更承認: 変更前後の目的・範囲・完了条件と、進行計画・WBSへの波及（波及する場合は計画セットの承認も要る）
- 途中Sync承認: 正式に反映する候補と反映先

作業上の前提を置く場合は「案件の判断:」で始まる別の行にする。整合のための変更（台帳・索引・frontmatter）はファイル名だけを並べ、共通検査で整合を確かめる。

## 承認の記録

### A-01 開始承認

- 状態: 承認済み
- 提示: YYYY-MM-DD HH:MM 提示者
- 承認: YYYY-MM-DD HH:MM 承認者（記録の承認）
- 承認の発言: 「承認の発言を引用する」
- 判断が要る点:
  - 示した判断点を1行ずつ書く
- 整合のための変更: 変更するファイルを並べる
